# RookieDB Roadmap

**目标**：将 RookieDB 从课程作业升级为简历级项目，目标岗位：后端/基础架构工程师。

**简历叙事**："从零构建了一个支持 MVCC 并发控制、Client-Server 架构、SQL 子查询的关系型数据库，附带完整 benchmark 对比数据。"

**时间预算**：3 个月+

**策略**：核心做深（MVCC）+ 外围做广（网络层、SQL 扩展、可观测性）

## Phase 1: MVCC（约 6 周）

替换多粒度锁，实现 Snapshot Isolation。核心亮点，面试时能聊 30 分钟不重复。

**内容：**
- 版本链：每条 record 维护多个版本，带 `create_txn_id` / `delete_txn_id`
- 事务快照：事务开始时记录活跃事务集合，读取时只看可见版本
- 写冲突检测：First-Committer-Wins，两个事务改同一行时后者 abort
- 版本回收（GC）：后台清理旧版本
- 和现有 2PL 共存：通过配置切换，保留旧实现作为 benchmark 对照

**改动范围：**
- 新增 `mvcc/` 模块（VersionStore、TransactionSnapshot、ConflictDetector、GarbageCollector）
- 修改 `table/`（Record 增加版本元数据）
- 修改 `Transaction` 接口
- 新增 MVCC 专属测试

**面试话题**：SI vs SSI vs 2PL tradeoff、write skew、版本链对 cache 的影响、GC 策略（timestamp-based vs epoch-based）

---

## Phase 2: 网络层 + Client-Server 架构（约 3 周）

从嵌入式升级为 Client-Server，展示系统设计能力。

**内容：**
- TCP Server：监听端口，线程池管理客户端连接
- 自定义 wire protocol：简单文本协议（请求 `Q<len><sql>`，响应 `R<len><data>` 或 `E<len><error>`）
- 连接生命周期：连接绑定事务状态，支持跨消息 BEGIN/COMMIT/ROLLBACK
- Python 客户端：适配 `client.py`，交互式 REPL
- 优雅关闭：SIGTERM 时等待活跃事务完成

**改动范围：**
- 新增 `server/` 模块（RookieServer、ConnectionHandler、WireProtocol）
- 修改 `CommandLineInterface`（支持本地和网络两种模式）
- 更新 `client.py`
- 新增集成测试（多客户端并发）

**面试话题**：thread-per-connection vs event-driven、连接管理、协议设计、背压处理

---

## Phase 3: SQL 语法扩展（约 3 周）

利用 ANTLR4 灵活性，扩展 SQL 能力。

**内容：**
- 子查询：`WHERE col IN (SELECT ...)`、`FROM (SELECT ...) AS subq`
- HAVING：`GROUP BY col HAVING COUNT(*) > 5`
- 通用 WHERE 表达式：支持任意 expression 作为 WHERE 条件（现在只支持 `col op value`）
- UNION / UNION ALL

**不做：** Window Functions、关联子查询（correlated subquery）

**改动范围：**
- 修改 `RookieSQL.g4`
- 新增查询算子（SubqueryOperator、UnionOperator）
- 修改 `SelectStatementHandler` + `QueryPlan`
- 新增测试

**面试话题**：子查询的执行策略、去关联化思路、UNION 实现

---

## Phase 4: 可观测性 + 基准测试（约 2 周）

用数据说话，从"学生项目"升级为"工程项目"。

**内容：**
- 慢查询日志：超阈值查询记录 SQL、执行时间、扫描行数
- 执行统计：I/O 次数、buffer pool hit rate、实际 vs 估算行数
- EXPLAIN ANALYZE：在 EXPLAIN 基础上附加实际执行统计
- Benchmark 框架：
  - MVCC vs 2PL 吞吐量对比（不同读写比例）
  - 不同 join 算法性能对比（不同数据量）
  - Buffer pool hit rate 随数据量变化曲线
- 结果输出 CSV，可用 Python 画图

**改动范围：**
- 新增 `stats/` 模块
- 修改 `QueryOperator`（注入统计收集点）
- 修改 `BufferManager`（暴露 hit rate）
- 新增 `benchmark/` 目录

**面试话题**：性能分析方法论、如何定位瓶颈、benchmark 设计
